# Ideas

Copy [IDEA-TEMPLATE.md](IDEA-TEMPLATE.md) to a descriptive Markdown filename for a proposed improvement. Keep proposals small and describe user value, privacy/compatibility impact, and measurable acceptance criteria.

Use statuses `proposed`, `accepted`, `in-progress`, `done`, or `declined`. Move settled ideas to [archive/](archive/) when useful; do not turn the repository's idea folder into runtime configuration.
