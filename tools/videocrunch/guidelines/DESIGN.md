# Design direction

The user-approved interpretation of "basic moorkyz style" is a restrained **charcoal workspace, violet accents, and a PowerShell-blue live terminal**. No external brand assets or unprovided reference designs are assumed.

- Use system fonts for interface text and Consolas/monospace for terminal output and paths.
- Keep the new-export form primary; move technical options behind clear labels, not jargon.
- The compression trade-off must be understandable; original-only visibly disables compression choices.
- Use true running/completed/failed states. Do not fabricate percentages, sample history, file savings, or tool readiness.
- Keep download and playback actions distinct, explain codec limitations, and always preserve access to the original.
- Use semantic labels, native controls, visible focus, responsive layouts, sufficient contrast, reduced-motion support, and readable errors.
- Never render website URLs, native logs, or error strings as raw HTML.
- Use local assets only. The application must not depend on a CDN or remote font request.
