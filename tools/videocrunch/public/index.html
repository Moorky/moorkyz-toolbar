A QUICK GUIDE

Less setup. More playback.

A few things worth knowing before your first export.

01

Start with a link

Paste a public video page, direct video URL, or HLS/DASH stream. Use only videos you own or are authorized to download. The app does not bypass DRM, logins, or paywalls.

02

Choose your trade-off

Balanced keeps more detail. Crunch is the everyday choice. Extreme prioritizes size and caps width at 1280px. Compression is lossy and does not always produce a smaller file.

03

Keep the original

Every export keeps the downloaded source. Choose "Just the original" to skip compression. Some original codecs need a desktop player rather than a browser.

04

Watch anywhere, offline

Open the finished player here, or open index.html inside the export folder. The manifest records file sizes, SHA-256 hashes, and download attempts. Keep output folders private: stream URLs may contain temporary tokens.

First-time setup

Double-click Start-WebVideoCrunch.cmd. Missing prerequisites are installed automatically through winget; Windows may ask for approval. If automatic setup is unavailable, install them manually:

winget install OpenJS.NodeJS.LTS
winget install yt-dlp.yt-dlp
winget install Gyan.FFmpeg

Keep the app terminal open while using VideoCrunch. One export runs at a time; no files are uploaded to a hosted service. Closing the app during an export can interrupt it.
