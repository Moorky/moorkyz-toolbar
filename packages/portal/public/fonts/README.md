# Self-hosted typography

Unmodified fonts from the Google Fonts repository, downloaded 2026-10-17:

- `DMSans.ttf`: `ofl/dmsans/DMSans[opsz,wght].ttf`, DM Sans variable font.
- `DMMono-Regular.ttf`: `ofl/dmmono/DMMono-Regular.ttf`, DM Mono regular.

Source: <https://github.com/google/fonts>. These assets are licensed under SIL
OFL 1.1, **not** the repository's Apache-2.0 license. The complete upstream
copyright and license notices are included in `DMSans-OFL.txt` and
`DMMono-OFL.txt`. Keep those notices with redistributed fonts.

The portal serves these files locally; no Google Fonts CDN or runtime external
font request is used. Generated consumer projects name DM Sans with a system
fallback; copy these separately licensed assets and their notices into a host
if identical typography is desired.
