# Security

Report suspected vulnerabilities privately through [GitHub security advisories](https://github.com/Moorky/moorkyz-tools/security/advisories/new). If private reporting is unavailable, contact the repository owner without publishing exploit details or credentials.

The default branch is the maintained development line. Keep dependencies and the container base current through reviewed Dependabot updates. CI executes locked installs and security checks before deployment. Do not commit secrets, local logs, archives or user data.

Production credentials belong in the GitHub `production` environment and Coolify runtime settings. Review reports and fixes individually; no response-time or support guarantee is implied.
