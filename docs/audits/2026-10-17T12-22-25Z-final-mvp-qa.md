### Implemented corrections

1. **Width:** the user explicitly confirmed that the entire Playground may be
   wider than the other sections. Reduced only its gutters; other content
   sections retain their alignment. Desktop/mobile containment is tested.
2. **Fullscreen/mobile:** moved Preview/Customize/Code and visible status into
   fullscreen; preserved exit/focus restoration, native and denied-API fallback,
   keyboard dismissal and responsive mode transitions.
3. **Sheet accessibility:** obscured application controls are inert while mobile
   settings/code are active. The selected accordion heading is kept visible by
   scrolling only the sidebar; the surrounding page and preview do not jump.
4. **Floating-interface collision:** the preview's bottom mount uses native
   sticky containment to stay clear of the page dock at intermediate scroll
   positions, retaining stored geometry and explicit manual collapse.
5. **Geometry:** centered X offsets now move by the entered amount when space
   permits; top-anchor pointer/keyboard Y direction matches its numeric model.
   Preview content reserves room for actual toolbar size/offset.
6. **Application isolation:** unfinished Workspace and Board titles are separate;
   resetting another application does not discard them.
7. **Document reliability:** commands share typing's 10,000-character bound, even
   during rapid invocation. Unicode case expansion preserves the actual
   selection range and cannot exceed that bound.
8. **Exports:** shared owned-URL cleanup and explicit failure feedback cover
   Playground, workbench and starter downloads. Valid source remains copyable.
9. **Generation:** extracted a memoized Quick Start lifecycle with visible loading,
   failure and retry, cancellation of superseded results and no stale export.
10. **Interrupted editing:** unapplied JSON/color buffers warn before leaving.
    They are not silently persisted as unvalidated data. Deliberate discard
    restores ordinary navigation; last-valid design persistence is unchanged.
11. **Clipboard/typography:** copy failures/success are visibly announced, targets
    are consistent, and actual code blocks use DM Mono rather than a more
    specific fallback-font rule.
12. **Themes:** explicit paired foreground/surface tokens fix stale inherited
    WebKit text colors after responsive light/dark transitions, including tables.
13. **Reflow:** header/navigation, context picker/readout, code headers, fieldsets,
    legends, technical labels and documentation now reflow at 200% text size.
14. **Search:** Escape closes a dialog with a nonempty native search field instead
    of merely clearing the query.
15. **SDK resize lifecycle:** overflow writes are coalesced outside ResizeObserver
    delivery; pending animation frames are cancelled on update/disposal. This
    fixes observer feedback rather than hiding its warning.
16. **React collapse:** carried manual collapse across the adapter's documented
    controller replacements. Kept identity-change/recreation/callback ownership
    semantics; no public API, feature default or framework boundary was changed.
17. **Rendering:** inactive editor panels acquire no controls; JSON serialization/
    validation is deferred until its editor is active. Unapplied parent-owned
    buffers survive accordion changes. Geometry-only changes do not rebuild the
    SDK action row.

Relevant decisions: Q07-10, Q12-13, Q15, Q18-21, Q28, Q31-32, Q35, Q37-45,
Q48, Q52-55, Q63-64, Q69-75 and Q79-80. Four applications, ten styles and
Vanilla-only generation remain the feature scope.

## 4. Risk and quality review

- **Public contracts:** preserved configuration/controller names, exports,
  feature defaults, one-package architecture, SSR safety and optional framework
  boundaries. React ownership replacement remains documented and tested; only
  unwanted expansion is prevented.
- **Security/privacy:** no arbitrary JS, privileged markup, new host permission,
  remote telemetry, learning, account, cloud/share service or secret retention.
  Existing fail-closed authorization and strict CSP regressions still pass.
- **Accessibility:** real keyboard/axe/contrast/large-text/focus/error checks,
  with no suppressed ResizeObserver or contrast warnings. Corrected semantic
  foregrounds rather than weakening scans. Manual WCAG acceptance is separate.
- **Error/recovery:** URL ownership, explicit generation retry, visible download/
  clipboard/storage failures and superseded-result protection retain valid work.
  Browser cancellation preserves unapplied text; leaving deliberately can still
  discard it, while the last valid saved design remains recoverable.
- **Resources:** native sticky containment adds no scroll polling. Media-query,
  fullscreen and beforeunload listeners are owned/released. SDK observer frames
  are coalesced/cancelled; disabled optional features retain their inactivity.
- **Maintainability:** extracted only generation/download concerns with concrete
  failure/lifecycle benefits. Avoided a repository-wide rewrite or new framework/
  dependency. Editor controls/validation are acquired only when needed.
